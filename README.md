# Our Universe

Статический романтический сайт для публикации через GitHub Pages.

## Быстрый запуск
1. Создай репозиторий на GitHub.
2. Загрузи `index.html` в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch, ветку `main`, папку `/ (root)`, затем Save.
5. Через некоторое время GitHub покажет публичный адрес сайта.

## Управление
- Для правок исходника: открой `index.html` в репозитории и нажми Edit (карандаш), затем Commit changes.
- В самом сайте есть локальный редактор по ссылке `admin` внизу справа. Он сохраняет изменения только в текущем браузере и умеет экспортировать `site-content.json`.
- Чтобы изменения редактора стали видны всем посетителям, нужно перенести содержимое экспортированного JSON в исходный сайт и опубликовать обновлённый `index.html`.

## Важно про безопасность
Встроенный редактор — удобный локальный инструмент, а не настоящая защищённая админ-панель. В статическом HTML нельзя безопасно хранить пароль, а localStorage не синхронизируется между устройствами. Для настоящей админки с входом по паролю и общими изменениями для всех посетителей нужно подключить backend (например, Supabase или Firebase) с серверной авторизацией и базой данных. Не вводи в статический HTML реальные пароли или секретные ключи.
